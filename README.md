# Puissance 4 en Python 🎮

Un petit jeu **Puissance 4** écrit en Python, jouable directement dans le terminal.  
Deux joueurs s’affrontent à tour de rôle pour aligner **4 pions identiques** horizontalement, verticalement ou en diagonale.

---

## Fonctionnalités ✨

- Grille de **6 lignes × 7 colonnes**  
- Affichage simple dans la console  
- Détection automatique de la victoire  
- Gestion des coups invalides (colonnes pleines ou hors limites)  
- Jeu 100% terminal, pas besoin d’interface graphique
